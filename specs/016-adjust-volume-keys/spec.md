# Feature Specification: 播放器上下键调节音量

**Feature Branch**: `016-adjust-volume-keys`

**Created**: 2026-07-25

**Status**: Implemented — manual post-fix acceptance pending

**Input**: User description: "把在播放器界面敲击上下键改为增减音量大小10"，并取消重复音量提示、支持底部音量条拖动与悬停显示当前音量。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 使用方向键快速调节音量 (Priority: P1)

用户在播放器界面观看或收听内容时，可以按上方向键增大音量、按下方向键减小音量，每次恰好调整 10 个音量点，从而无需打开音量控件即可快速获得可感知且一致的音量变化。

**Why this priority**: 这是本功能的核心价值，直接缩短播放期间调节音量的操作路径。

**Independent Test**: 在播放器中将音量设为非边界值，分别按一次上方向键和下方向键，确认音量依次增加和减少 10 个点，即可独立验证该功能。

**Acceptance Scenarios**:

1. **Given** 用户位于播放器界面且当前音量为 40，**When** 用户按一次上方向键，**Then** 音量变为 50。
2. **Given** 用户位于播放器界面且当前音量为 40，**When** 用户按一次下方向键，**Then** 音量变为 30。
3. **Given** 用户位于播放器界面且当前音量为 40，**When** 用户先按一次上方向键再按一次下方向键，**Then** 音量最终回到 40。

---

### User Story 2 - 在音量边界安全调节 (Priority: P2)

用户在音量接近最大值或最小值时继续使用方向键，音量保持在有效范围内，不会出现越界值或异常行为。

**Why this priority**: 边界行为必须可预测，才能让核心快捷键在所有音量状态下可靠使用。

**Independent Test**: 分别从接近最大值、最大值、接近最小值和最小值按对应方向键，确认音量始终限制在 0 至 100。

**Acceptance Scenarios**:

1. **Given** 当前音量为 95，**When** 用户按一次上方向键，**Then** 音量变为 100。
2. **Given** 当前音量为 100，**When** 用户按一次上方向键，**Then** 音量保持为 100。
3. **Given** 当前音量为 5，**When** 用户按一次下方向键，**Then** 音量变为 0。
4. **Given** 当前音量为 0，**When** 用户按一次下方向键，**Then** 音量保持为 0。

### User Story 3 - 直接操作底部音量条 (Priority: P2)

用户可以点击或拖动播放器底部的蓝色音量条调整音量，并在鼠标悬停于音量旋钮或拖动期间看到当前音量百分比；键盘调节不再显示 mpv 默认的中央白色进度条或左上角音量文字。

**Why this priority**: 鼠标拖动提供连续、精确且可发现的音量控制，同时避免重复反馈遮挡视频内容。

**Independent Test**: 从音量条任意位置按下并持续拖动到两端，确认音量连续更新至 0–100，窗口不随拖动移动，悬停旋钮时显示当前百分比。

**Acceptance Scenarios**:

1. **Given** 鼠标位于音量条，**When** 用户点击任意位置，**Then** 音量映射到该位置对应的 0–100 值。
2. **Given** 用户按住音量条并跨越多个位置拖动，**When** 指针移动超过 3 像素，**Then** 音量持续更新且播放器窗口保持原位。
3. **Given** 鼠标悬停在音量旋钮上，**When** 未进行拖动，**Then** 旋钮上方显示与时间标签同字号的当前音量百分比。
4. **Given** 用户使用上下键调节音量，**When** 音量发生变化，**Then** 仅底部自定义控件反映状态，不出现中央白色进度条或左上角音量文字。

---

### Edge Cases

- 当前音量不是 10 的整数倍时，按键仍以当前值为基准增减 10，并在 0 或 100 处截断。
- 用户长按方向键并触发多次有效按键事件时，每次事件均调整 10，直至达到对应边界。
- 当焦点位于可编辑文本区域时，上下方向键保留文本编辑或光标移动行为，不调节音量。
- 用户不在播放器界面时，上下方向键不触发本功能。
- 调整至 0 后再次按上方向键，音量变为 10，以便用户恢复声音。
- 本功能不得改变播放器中其他键盘快捷键的既有行为。
- 音量拖动离开音量条水平范围时，结果必须限制为 0 或 100，直到释放鼠标。
- 顶部窗口拖动区域与音量条、窗口按钮互不重叠；拖动音量条不得触发窗口移动。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 当播放器界面处于活动状态且焦点不在可编辑文本区域时，系统 MUST 将一次上方向键操作解释为音量增加 10 个点。
- **FR-002**: 当播放器界面处于活动状态且焦点不在可编辑文本区域时，系统 MUST 将一次下方向键操作解释为音量减少 10 个点。
- **FR-003**: 系统 MUST 将音量限制在包含 0 和 100 的有效范围内，任何方向键调节均不得产生越界值。
- **FR-004**: 当剩余边界距离小于 10 时，系统 MUST 将音量设置为相应边界，而不是忽略该次操作或越过边界。
- **FR-005**: 系统 MUST 对每次有效的重复按键事件应用一次 10 点调整，使长按行为与连续单击保持一致。
- **FR-006**: 当焦点位于可编辑文本区域时，系统 MUST NOT 使用上下方向键调节音量。
- **FR-007**: 当用户不在播放器界面时，系统 MUST NOT 因上下方向键触发本功能。
- **FR-008**: 调节音量后，系统 MUST 通过播放器既有的音量状态或反馈向用户反映最新音量。
- **FR-009**: 系统 MUST 保持上下方向键以外的现有键盘快捷键行为不变。
- **FR-010**: 系统 MUST 支持通过点击或持续拖动底部音量条设置 0–100 范围内的音量。
- **FR-011**: 鼠标按住音量条移动时，系统 MUST 持续更新音量，直至左键释放。
- **FR-012**: 系统 MUST NOT 在音量拖动达到 mpv 窗口拖动死区后将操作转换为窗口移动。
- **FR-013**: 鼠标悬停音量旋钮或正在拖动时，系统 MUST 在旋钮附近显示当前整数音量百分比，字号与进度条时间标签一致。
- **FR-014**: 系统 MUST NOT 显示 mpv 默认的中央音量进度条或左上角自定义音量文字。
- **FR-015**: 系统 MUST 保留顶部非按钮空白区域移动播放器窗口的能力。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在 0 至 100 的全部初始整数音量值下，单次有效按键产生的结果 100% 符合“增减 10 并在边界截断”的规则。
- **SC-002**: 用户按下有效方向键后，可在 0.5 秒内从播放器反馈中确认更新后的音量。
- **SC-003**: 在覆盖播放器内外、可编辑与不可编辑焦点的验收测试中，100% 的方向键操作仅在规定范围内调节音量。
- **SC-004**: 至少 95% 的测试用户无需打开音量控件，即可首次正确使用上下方向键完成一次增大和一次减小音量操作。
- **SC-005**: 现有非上下方向键快捷键的回归验收通过率为 100%。
- **SC-006**: 音量条从任意起点拖动至两端时，音量连续更新并准确达到 0 与 100。
- **SC-007**: 100% 的音量条拖动操作不会触发播放器窗口移动。
- **SC-008**: 悬停提示与拖动提示显示的音量值和播放器实际音量一致。

## Assumptions

- 播放器使用 0 至 100 的用户可见音量范围，文中的“大小 10”解释为每次调整 10 个音量点。
- “播放器界面”指内容正在播放器视图中展示且该视图接收键盘输入的状态。
- 可编辑文本区域包括用户可以输入或修改文字的控件；这些区域优先保留标准方向键行为。
- 播放器已有可反映当前音量的状态或反馈，本功能复用该反馈，不新增独立的展示形式。
- 本功能扩展现有 mpv Lua 控件的鼠标音量交互，不新增 renderer 输入路径或持久化设置。
